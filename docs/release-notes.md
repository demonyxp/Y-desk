# Y-Desk v0.5.0

- 新增自动画质：1080p / 30 帧目标，双屏总码率初始 8 Mbps、范围 1.5–12 Mbps；按可用带宽与编码负载调整。采集尺寸跟随画质档位，保留四档手动设置与隐藏屏幕暂停发送。
- 网络短暂中断后，在原授权会话内尝试 ICE 重连，最多两次；主动断开立即取消。
- 双屏新增窗口交换、指定本地显示器、原始大小 / 适应窗口，以及全屏自动隐藏工具栏。
- 新增最近设备、备注与收藏；成功连接后记录设备码和服务器，不保存对方密码。
- 新增双向纯文本剪贴板，两端显式开启后生效；默认关闭，单次上限 64 KiB，断开即停止。
- 新增双向普通文件传输：单文件最多 2 GB，支持进度、取消、接收确认、指定目录自动接收。同名改名、失败清理临时文件、不自动打开。独立数据通道并限速，暂不支持文件夹及断点续传。
- 新增信令 / TURN 检测、编码限制提示和脱敏诊断导出。初次使用默认填入 desk.yinsane.xyz；旧配置继续沿用。

## 下载与升级

- Y-Desk-Setup-0.5.0-win-x64.exe：Windows 10/11 x64 安装版。
- Y-Desk-0.5.0-win-x64.exe：免安装版。
- latest.yml 与 .blockmap 由自动更新使用，无需手动校验。

建议两台电脑一起升级。安装版点击“检查更新”，下载后先结束远程会话再安装；便携版下载替换。设备码和无人值守配置保留，现有 Go 信令服务及 coturn 无需重装。

文件与剪贴板位于连接中的“工具”；被控端点击“文件与剪贴板”。无人值守自动接收需要在本机事先选择目录并开启。旧客户端可以继续远控，新增协作功能需要双方升级。

网络 RTT、硬件和跨境路由仍影响体验；静止桌面低帧率属于正常节流。此次未登录或改动用户的韩国服务器，未实测用户的跨境链路。不支持 UAC 安全桌面、无人登录界面或虚拟显示器驱动。
