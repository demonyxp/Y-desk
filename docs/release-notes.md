# Y-Desk v0.2.2

- 修复设备码只在服务器连接成功后显示的问题：启动即显示本机固定设备码，离线、连接失败、停止共享后仍可查看和复制。

- 自设连接密码（8–128 个字符），不再使用随机 32 位密钥。
- 固定设备码，重启客户端和信令服务器后保持不变。
- 无人值守：密码正确自动连接，无需在被控端点击允许。
- Windows 加密保存配置；托盘常驻、断网重连、重启恢复共享。
- 安装版支持 Windows 登录后自动启动；主动停止共享后不会自动恢复，需手动再次开启。
- 保留双屏并排/切换、高清画质、鼠标键盘控制及中文输入。
- 修复标签构建中打包器重复触发发布的问题，由 GitHub Actions 统一上传发布包。

## 下载

- `Y-Desk-Setup-0.2.2-win-x64.exe`：推荐安装版，支持登录自启。
- `Y-Desk-0.2.2-win-x64.exe`：免安装版，解压运行时后直接启动，支持无人值守，不支持登录自启。
- `SHA256SUMS.txt`：下载校验值。

两端均需 Windows 10/11 x64。首次开启共享时设置自己的密码，按需勾选无人值守。下载包不含任何预设密码或个人设备信息。

本版本升级了认证协议，客户端和自托管信令服务器必须一起升级；旧版 v0.1.0 不兼容。信令服务新增持久化设备注册表，Docker 部署需保留 `signaling_data` 卷。

仍需自己的 WSS / TURN 服务；下载安装程序并不会自动获得公共中继服务。无人值守作用于已经登录的 Windows 桌面，不支持登录界面、UAC 安全桌面或远程开机；锁屏/休眠暂停共享，解锁/唤醒后重连。

程序尚未商业代码签名。源码、部署方法和完整限制见仓库 README。
