# Y-Desk v0.4.0

- 中继配置改为地址、账号、密码表单；地址留空自动使用信令域名。配置加密保存在本机，普通共享和控制端重启后也能回填。高级 JSON 配置继续支持。
- 新增“双屏分窗”：远端屏幕 2 在独立窗口显示，优先放到本地第二个显示器；可以单独全屏、控制、合并回主窗口。复用现有视频流，不重复编码或传输。
- 修正全屏布局，让远程画面使用剩余屏幕空间；保留退出全屏和断开按钮。十字光标改为普通箭头。
- 鼠标移动使用独立的无序、无重传通道，过滤过期位置；点击、按键、释放和心跳继续可靠传输。与旧客户端连接时可回退。
- 默认流畅档，新增低带宽档；两屏共用码率预算，只看一屏时暂停另一屏发送。降低采集帧率和接收缓冲目标，避免不必要的处理和排队。
- 连接信息显示直连/中继、UDP/TCP、RTT，以及每屏帧率、码率和接收缓冲时间，方便区分网络和处理延迟。静止桌面低帧率不一定代表异常。

## 下载与升级

- `Y-Desk-Setup-0.4.0-win-x64.exe`：Windows 10/11 x64 安装版。
- `Y-Desk-0.4.0-win-x64.exe`：免安装版。
- `latest.yml` 和 `.blockmap` 由自动更新程序使用，无需手动操作。

建议两台电脑一起更新。v0.3.0 安装版可点击“检查更新”；下载完成后结束远程连接，再点击“重启并安装”。设备码和无人值守设置沿用，现有 Go 信令服务端及 coturn 不需要重装。

本地验证包括实际单屏采集、模拟双屏传输、分窗控制和清理、全屏、中继配置保存、无人值守及更新回归。没有实测用户的跨境链路或两台物理显示器组合，软件优化不能消除网络 RTT，也不保证任意网络下无卡顿。
