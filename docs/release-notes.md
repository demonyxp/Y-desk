# Y-Desk v0.3.0

- 新增自动检查更新：启动 15 秒后检查，此后每 6 小时检查一次；右上角可手动检查。
- 安装版支持程序内下载、进度显示及“重启并安装”，下载文件通过 SHA512 校验。
- 有远程连接或待处理连接请求时拒绝安装；普通退出或关闭窗口不会自动安装更新。
- 更新检查失败不影响共享，可手动重试。无人值守密码和设备码继续保存在原来的加密配置中。
- 便携版支持检查新版，通过下载页手动替换；推荐使用安装版获得程序内升级。

## 下载与升级

- `Y-Desk-Setup-0.3.0-win-x64.exe`：Windows 10/11 x64 安装版，支持登录自启和程序内更新。
- `Y-Desk-0.3.0-win-x64.exe`：免安装版。
- `SHA256SUMS.txt`：手工下载校验值；`latest.yml` 和 `.blockmap` 供更新程序使用。

**v0.2.2 及以前没有自动更新模块，需手动下载安装 v0.3.0 一次。** 之后发现新版本时点击“下载更新”，下载完成并结束远程连接后，点击“重启并安装”。保持默认安装位置即可沿用设备配置。本次没有修改信令协议，已有 v0.2.x 服务端可继续使用。

仍需自建 WSS / TURN 服务；无人值守需要 Windows 已登录，不支持登录界面或 UAC 安全桌面。更新需要能访问 GitHub。程序尚未商业代码签名；发布文件来自本仓库，通过 HTTPS 下载和发布元数据中的摘要校验。
